# Video

Optional. One slot, attached to the final letter at the Wish Tree.

1. Put an `.mp4` here, e.g. `public/video/final-note.mp4`
2. Set `video.src` to `"/video/final-note.mp4"` in `data/finale.ts`

It never autoplays, and if the file is missing the player hides itself.
Keep it short and small — phones download the whole thing.
